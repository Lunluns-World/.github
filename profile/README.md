## 關於我們

Lunlun's World 是以 Minecraft 為核心的台灣玩家社群，經營長期營運的多人伺服器，重心放在玩家之間的交流與合作。

- **長期向玩法**：生存、建築、紅石，搭配經濟與職業系統
- **多分流架構**：多個生存分流與副本分流，玩家資料跨分流同步
- **社群優先**：遊戲內聊天與 Discord 雙向互通，活動與公告同步發布
