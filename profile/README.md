# Lunluns-World

Lunlun's World（LLsMC 侖侖伺服器）是一個以 Minecraft 為核心的社群組織，主要經營長期向的多人遊戲伺服器，並以玩家社群互動為發展重點。

## 我們是怎麼樣的組織

- 以 Minecraft 社群經營為主軸，提供公開連線的玩家伺服器。
- 玩法聚焦在生存、建築與紅石等長期發展內容，並結合經濟與職業等系統。
- 重視社群交流與合作，透過伺服器與社群平台維持玩家互動與活動。
